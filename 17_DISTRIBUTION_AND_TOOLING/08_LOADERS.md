# Application Loaders

Estado: **PRODUCT REQUIREMENT**

Los loaders forman parte del cierre de producto.

No tratarlos como detalle cosmético postergable indefinidamente.

## ADA Generic

Baseline visual aprobado:

- identidad ADA;
- descriptor `Asistente de Decisiones Ágiles`;
- tool name variable;
- branding gris/institucional;
- animación suave;
- loader asociado al startup/readiness real.

## Manager

Mantiene loader/shell coherente con su identidad y header propios.

## Command Center

Debe tener loader propio coherente con Command Center cuando se diseñe su Web.

## Regla

Loader representa:

```text
application startup / readiness
```

No debe ocultar errores indefinidamente.

Si bootstrap falla:

```text
loader
→ termina
→ readiness/error surface
```
