# Atlanticus University — Purpose

Estado: **CURRENT**

## Objetivo

Atlanticus necesita una capa pedagógica para:

- clases;
- onboarding;
- transferencia de conocimiento;
- demostración de capabilities;
- comprensión de arquitectura.

No es:

- unit test;
- integration test;
- qualification;
- README alternativo.

## University Case

Un caso de University es un ejemplo **real, pequeño y aislado** que demuestra una capability con lógica fácil de entender.

Ejemplos de dominios:

- configuration;
- Cosmos;
- Storage;
- Dataset Runtime;
- Source/Producer;
- KPI;
- Alarm;
- Users/Profile;
- Navigation;
- User Activity;
- Manager;
- Web composition.

## Valor

El código productivo puede ser complejo por necesidades reales.

University permite enseñar:

```text
una idea
→ un caso
→ una entrada
→ una salida
```

sin mezclar toda ADA.
