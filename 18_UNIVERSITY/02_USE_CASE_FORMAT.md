# Atlanticus University — Use Case Format

Estado: **CURRENT DIRECTION**

Cada caso debe incluir:

## 1. Problem

Una situación concreta.

## 2. What it teaches

Una sola capability principal.

## 3. Input

Datos pequeños y legibles.

## 4. Flow

Pasos cortos.

## 5. Output

Resultado verificable visualmente o por consola.

## 6. Explanation

Explicación pedagógica en español.

## 7. Real-world mapping

Dónde aparece ese concepto en Atlanticus/ADA real.

## 8. Try it

Comando simple para ejecutar local.

## Regla

Un caso no necesita pytest para demostrar valor.

Puede reutilizar librerías productivas, pero no se convierte en dependencia de producción.
