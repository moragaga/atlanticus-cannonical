# ADA Generic — Scope

Estado: **CURRENT DIRECTION**

## Propósito

ADA Generic es la base reutilizable que integra configuración y capacidades transversales necesarias para materializar una ADA.

No debe convertirse en una megaaplicación que absorba cada regla de negocio de las herramientas finales.

## Alcance objetivo

Integrar/resolver desde configuración:

- identidad de Tool;
- Tool Structure;
- branding;
- navegación;
- sources/participación;
- Component/Collector contracts;
- KPI configuration/definition;
- alarm configuration/projection;
- render binding;
- runtime experience;
- demás contratos configurables aprobados.

## Handoff

Una vez resuelta la base/configuración, el usuario puede continuar construyendo o generando el código específico de su ADA sobre contratos estables.

ADA Generic habilita autoservicio/composición.

No sustituye el código específico cuando una Tool requiere comportamiento propio legítimo.

## Frontera

Atlanticus aporta capacidades genéricas.

ADA Generic las compone para ADA.

La Tool final aporta sus particularidades sin contaminar la plataforma.
