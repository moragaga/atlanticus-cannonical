# ADA Command Center — Initial Out of Scope

Estado: **CURRENT DIRECTION**

Inicialmente no son obligatorios para cerrar el Golden Path:

- Tool authoring;
- generic Actions page;
- automatic configuration merge;
- AI como autoridad analítica;
- Strategic-specific behavior sin evidencia;
- nueva infraestructura especulativa.

No introducir por defecto:

- Redis;
- Event Grid;
- Service Bus;
- streaming;
- microservices.

## User Activity

NO queda prohibido.

Es capability transversal opcional.

Puede integrarse cuando queramos trazabilidad de uso de Command Center sin modificar:

- Alarm Engine;
- History/Analytics;
- Navigation;
- Users core.

No debe bloquear el primer Golden Path si aún no es necesaria para demostrar alarm lifecycle/analytics.

## Refresh

App/session auto-refresh no se hereda automáticamente de ADA Generic.

La actualización de datos Live/Analytics se diseña por separado.
